📌 Project 1 — Carint
HTML • CSS • JavaScript
A responsive, interactive car showcase / landing page built using HTML, CSS and JavaScript.

🌟 Project Overview:
Carint is a modern, lightweight web interface designed to showcase car information, features, and interactions using vanilla HTML, CSS, and JavaScript.
Whether it’s a landing page for a car brand or an interactive UI for car browsing, this project demonstrates core frontend skills with smooth design and functionality.
        Carint is designed to demonstrate front-end web development fundamentals with a clean UI, responsive layout, and interactive elements.
The project focuses on user experience, smooth scrolling, and dynamic behavior using JavaScript.

✨ Built for learning and showcasing front-end fundamentals.

🧩 Features
✔️ Fully responsive layout
✔️ Navigation bar interactions
✔️ Smooth transitions & hover effects
✔️ JavaScript-driven UI logic
✔️ Modular and clean code structure

🔧 Built With

Technology	              Purpose
⭐ HTML	                  Layout & Structure
🎨 CSS	                  Styling & Responsiveness
⚙️ JavaScript	            Interactivity & Logic

🧠 How It Works

1.HTML structure defines each section of the page.
2.CSS styles visuals and handles responsiveness (grid/flex/layouts).
3.JavaScript adds user interactions (menu toggles, car sliders, animations, etc.)
