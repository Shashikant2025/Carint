# 📌 Project 1 — Carint  
### HTML • CSS • JavaScript

A responsive, interactive car showcase / landing page built using **HTML**, **CSS**, and **JavaScript**.

---

## 🌟 Project Overview

Carint is a modern, lightweight web interface designed to showcase car information, features, and interactions using vanilla HTML, CSS, and JavaScript.

Whether it’s a landing page for a car brand or an interactive UI for car browsing, this project demonstrates core front-end skills with smooth design and functionality.

Carint is designed to demonstrate front-end web development fundamentals with:
- A clean user interface  
- Responsive layout  
- Interactive elements  

The project focuses on:
- User experience  
- Smooth scrolling  
- Dynamic behavior using JavaScript  

✨ Built for learning and showcasing front-end fundamentals.

---

## 🧩 Features

- ✔️ Fully responsive layout  
- ✔️ Navigation bar interactions  
- ✔️ Smooth transitions & hover effects  
- ✔️ JavaScript-driven UI logic  
- ✔️ Modular and clean code structure

| Technology | Purpose |

---

## 🧠 How It Works

1. **HTML** defines the structure and sections of the page  
2. **CSS** styles the visuals and manages responsiveness using Flexbox/Grid  
3. **JavaScript** adds interactivity such as:
   - Navigation behavior  
   - Sliders  
   - Animations  
   - UI interactions
